# AGENTS.md

Contexto para agentes de IA que trabalham neste repositório.

## Sobre o projeto

`clone-tab-news-ai` é um clone do **TabNews** (tabnews.com.br), a plataforma de conteúdos e notícias de tecnologia criada por Filipe Deschamps e usada como projeto no curso.dev. O projeto é construído com ajuda de IA.

## Stack

- Next.js com App Router (pasta `app/`)
- React
- JavaScript (sem TypeScript)

## Comandos

```bash
npm install     # instala as dependências
npm run dev     # servidor de desenvolvimento (next dev)
npm run build   # build de produção (next build)
npm run start   # sobe o build de produção (next start)
```

## Convenções

- Idioma da interface e das mensagens de commit: português (pt-BR).
